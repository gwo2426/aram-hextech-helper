## ✨ 功能特色

### 🔮 海克斯符文数据库
- **47个符文**：包含棱彩、金色、银色三个稀有度
- **详细效果说明**：每个符文都有完整的中英文名称和效果描述
- **智能搜索**：支持按名称、英文名、效果关键词搜索
- **分类筛选**：按稀有度和类型（伤害增幅、坦度增强等）快速筛选

### 🎯 英雄推荐系统
- **172个英雄**：覆盖所有英雄联盟英雄
- **胜率数据**：实时ARAM模式胜率排名
- **定位分类**：按战士、法师、射手、坦克、辅助、刺客分类
- **符文推荐**：为每个英雄推荐最适合的海克斯符文

### 🔥 符文套路Build
- **8个精选套路**：大法师流、辅助之神、ADC Carry流等
- **详细分析**：每个套路包含优劣势分析和进阶技巧
- **适用英雄**：明确标注每个套路适合哪些英雄
- **流派分类**：按输出、坦克、辅助、混合分类

---

## 🎨 设计风格

采用**赛博朋克未来主义**设计理念：

- **视觉语言**：霓虹青色与紫色渐变，六边形几何图案
- **字体系统**：Orbitron科技感标题 + Noto Sans SC现代正文
- **交互动画**：流畅的悬停效果和过渡动画
- **响应式设计**：完美支持桌面、平板和手机

---

## 🚀 技术栈

- **前端框架**：React 19 + TypeScript
- **样式方案**：Tailwind CSS 4
- **UI组件**：shadcn/ui
- **路由**：Wouter
- **构建工具**：Vite

---

## 📦 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```
